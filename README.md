# Componente de Código QR

Exercício de composição visual de um card com imagem de QR code, desenvolvido em HTML e CSS.

## O que o projeto apresenta

- Estrutura do card em HTML.
- Estilização em arquivo CSS dedicado.
- Imagem de QR code e favicon incluídos.

## Tecnologias

HTML · CSS

## Executar localmente

Clone o repositório e abra `index.html` no navegador. Para servir os arquivos localmente, use um servidor estático, como Live Server. Não há etapa de build.

## Estrutura

- `QR.css`
- `favicon-32x32.png`
- `image-qr-code.png`
- `index.html`

## Estado atual

Componente estático para estudo de layout e apresentação de conteúdo.
